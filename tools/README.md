# @webforge/tools

Repository scripts. Each script is a single TypeScript file that Node 24 runs directly (type stripping). They have no relative imports, because Node does not map `./foo.js` to `foo.ts`.

| Script                        | Run with                                          | What                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ----------------------------- | ------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/build-app-icons.ts`      | `pnpm app-icons`                                  | Draws the desktop app's icons (`icon.ico`, `icon.icns`, Linux PNGs) from the logo's masters in `apps/desktop/branding` into `apps/desktop/build`, and records the masters' SHA-256 in `icon-sources.json`; a test fails when the icons are older than their masters. Run it after changing a master and commit the result                                                                                                                                            |
| `src/build-behaviours.ts`     | `pnpm behaviours`                                 | Writes `packages/site-components/src/behaviours/index.ts`, the text of each `webforge.js` behaviour by name, so the package loads in plain Node. A site-components test fails when it is stale                                                                                                                                                                                                                                                                       |
| `src/build-font-catalogue.ts` | `pnpm font-catalogue`                             | Writes `packages/themes/src/fonts/catalogue.json` (2.2): the ~50 bundled families and their pairings, read from Fontsource's pinned API (v1). It refuses any licence but OFL-1.1, Apache-2.0 and UFL-1.0 (C1), and records each bundled file's npm package, version, size and SHA-256, staying within the installer's font budget. Needs the network; run it when the selection changes and commit the result                                                        |
| `src/bundle-side-effects.ts`  | the desktop app's build                           | Lists Webforge's own modules that do something when loaded, so the renderer's bundle drops the rest when nothing they export is used (#896). A test checks every import made only to load a module is listed                                                                                                                                                                                                                                                         |
| `src/check-area-cycles.ts`    | `pnpm deps`                                       | Fails when two areas of the desktop renderer depend on each other, directly or through others (B2)                                                                                                                                                                                                                                                                                                                                                                   |
| `src/check-help.ts`           | `pnpm help-check`                                 | Fails when a help page in `docs/help/` doesn't parse, links nowhere, spells out the app's name, or leaves a component type without its section (HP-5)                                                                                                                                                                                                                                                                                                                |
| `src/check-installer-size.ts` | CI's Performance job                              | Fails when an installer (`.exe`, `.dmg`) is over architecture §10's 150 MB                                                                                                                                                                                                                                                                                                                                                                                           |
| `src/check-licences.ts`       | `pnpm licence-check`                              | Fails if any installed dependency lacks a permissive licence (C1). Allow-list and reviewed exceptions live in the file; see [ADR 0002](../docs/adr/0002-licence-check.md)                                                                                                                                                                                                                                                                                            |
| `src/check-react-compiler.ts` | `pnpm react-compiler`                             | Fails when the React Compiler can't compile a component or hook, crashes, or is turned off with `"use no memo"` (ADR 0010)                                                                                                                                                                                                                                                                                                                                           |
| `src/check-ui-strings.ts`     | `pnpm ui-strings`                                 | Fails on hard-coded user-facing text (JSX text, and literals in `aria-label`, `title`, `placeholder`, `alt` and props ending in `Text`, `Label`, `Title`…, including inside `?:`, `&&`, `??` and template literals) in the `.tsx` files of the desktop renderer, `editor-ui`, `engine` (Puck overrides) and `site-components`; tests and stories are skipped. Parses with swc (TypeScript 7 has no JavaScript compiler API). Fixtures in `test/fixtures/ui-strings/` |
| `src/compare-bench.ts`        | CI's Benchmarks job                               | Compares `pnpm bench`'s results for two commits run in interleaved rounds, and fails a benchmark that is too slow in every round (ADR 0022)                                                                                                                                                                                                                                                                                                                          |
| `src/ensure-electron.ts`      | the desktop app's `dev` and `preview`             | Downloads Electron's binary when it is missing, so electron-vite starts on a fresh clone                                                                                                                                                                                                                                                                                                                                                                             |
| `src/new-component.ts`        | `pnpm new-component`                              | Writes a new site component family's module, story, test and strings, and registers it ([docs/components.md](../docs/components.md))                                                                                                                                                                                                                                                                                                                                 |
| `src/scaffold.ts`             | `pnpm scaffold`                                   | Writes a new area, panel, commands, kind of field or IPC domain of the editor, with its strings, story and test, and registers it ([docs/extending.md](../docs/extending.md))                                                                                                                                                                                                                                                                                        |
| `src/stage-rollout.ts`        | `node tools/src/stage-rollout.ts <tag> <percent>` | Moves a release to the Stable channel for a share of its installations, through `gh` ([docs/releasing.md](../docs/releasing.md))                                                                                                                                                                                                                                                                                                                                     |
| `src/template-placeholder.ts` | `node tools/src/template-placeholder.ts …`        | Draws a placeholder photo (CC0) for a template, the same every time for the same arguments                                                                                                                                                                                                                                                                                                                                                                           |
| `src/third-party-notices.ts`  | the desktop app's build                           | Writes the notices for every package the app ships, for the Open-Source Licences screen and `THIRD_PARTY_NOTICES.txt` (5.3)                                                                                                                                                                                                                                                                                                                                          |
| `src/visual-docker.ts`        | `pnpm visual:docker`                              | Runs the Storybook axe and screenshot tests in CI's pinned Playwright container (Docker), on a copy of the working tree as git sees it, and copies new or (with `--update`) changed screenshots back to `e2e/visual/__screenshots__/`. The image follows `@playwright/test` in `e2e/package.json`; a test checks it matches CI's Storybook job. Downloads are cached in the Docker volume `webforge-visual-cache`                                                    |

Three tests here check the repository rather than a script: the desktop app's entry point stays small (`desktop-entry.test.ts`, R13c), every panel has a story (`panel-stories.test.ts`, B6), and `@webforge/site-components/schema` loads in plain Node (`site-components-schema.test.ts`).
