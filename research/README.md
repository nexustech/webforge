## Stack decisions
| # | Question | Status | Outcome |
|---|---|---|---|
| 1 | [Desktop shell: Electron vs Tauri](stack/01-electron-vs-tauri.md) | Researched | **Electron** (pending a 2–3 day spike) |
| 2 | [Editor UI framework: React vs Svelte](stack/02-react-vs-svelte.md) | ✅ Decided | **React + shadcn/ui** |
| 2a | [Undo / redo design](stack/03-undo-redo.md) | ✅ Agreed | Zustand + Immer patches, custom history manager, history panel |
| 3 | [Canvas / editor engine](stack/04-canvas-engine.md) | Researched | **Puck** (MIT) pending 3–4 day spike; fallback = own canvas on dnd-kit + Tiptap |
| 3a | [Site components, theming & self-contained output](stack/05-site-components.md) | ✅ Decided | **daisyUI** (MIT) static components, distinct themes per site; all assets bundled, no CDNs |
| 4 | [Project file format & versions](stack/06-project-file-format.md) | Researched | Single-file **SQLite `.wforge`**, periodic autosave, named + last-20 automatic versions; ZIP fallback; 1–2 day spike |
| 5 | [Export pipeline (build & preview)](stack/07-export-pipeline.md) | ✅ Decided (X1–X6) | **In-app pipeline** (Puck render + Tailwind v4/daisyUI + esbuild + jSquash images) in a utilityProcess; same pipeline for live preview; no SSG |
| 6 | [Publishing](stack/08-publishing.md) | ✅ Decided (B1–B5) | **Folder/ZIP + FTP/FTPS/SFTP + Netlify**; form service presets (Formspree, Web3Forms, FormSubmit, Netlify Forms, custom); GA4 + consent banner; hosting deferred |
| 7 | [CI minutes if the repository goes private](stack/09-ci-minutes-private-repo.md) | ℹ️ Research for a later decision (CI-1…CI-6) | Three days of CI (25–28 Oct 2026) would count about 84,000 of GitHub Free's 2,000 monthly minutes if the repository were private, three quarters of it macOS. Proposed: stay public while three streams work; before going private, drop the merge queue's schedule, stop repeating unit tests on Windows and macOS, and move macOS to a schedule; then a self-hosted runner on the developer's PC with macOS weekly (an AWS Mac for about $90 a month, or GitHub's). Scheduled-only CI and AWS runners for all three systems (about $2,000–3,250 a month) are costed too |

| P8 | [Styling one section or element](product/08-component-styling.md) | ✅ Decided (ST-1…8) | How Webflow, Pinegrow, Elements and Bootstrap Studio (and, as context, Wix and Squarespace) style one component; Webforge had the thinnest per-element styling of the five. All in the MVP as Phase 2's styling block (ST-8): a common Appearance group of token controls on every section and element with a hover row (2.22), underline/highlight/colour inside text (2.25), section backgrounds (2.26), apply-to-all-of-a-kind (2.27), transition presets on hover (2.28) and a pass over the templates (2.29); the tokens-only rule kept in Simple mode |
| P6 | [Editor UI/UX parity](product/06-editor-ui-ux-parity.md) | ✅ Decided (UI2–UI5) | Bootstrap Studio interaction parity (canvas, selection, panels) and Elements ideas (Inspector cues, per-device dots, Theme Studio) in the MVP; Bootstrap Studio's shortcuts as the standard; v1.1 notes, workspaces, display modes, AI panel |
| P8 | [Start screen comparison](product/08-start-screen-comparison.md) | ✅ Decided (SC-1–SC-4) | Compared with Bootstrap Studio, Pinegrow, Mobirise, Elements and Webflow: larger type than the editor, the logo/name/version block, a first start that says what to do next, templates kept in New Site (2.14b) ¹ |
| P9 | [A quick start for a new site](product/09-quick-start-wizard.md) | ✅ Decided (QS-1…QS-8) | How Squarespace, Jimdo, Wix, Hostinger, GoDaddy, Durable, Framer and Mobirise run the first questions for a new site. A four-step quick start (business, look, pages, colours and details) whose answers pick the template, pages and palette and fill Site Settings, with the sample business replaced on creation and page recipes per business type, as the start screen's primary action (MVP, item 3.11, 5.5 days); a description step with the v1.1 assistant replaces G25c's Later |
| P10 | [What the competitors charge](product/10-competitor-pricing.md) | ℹ️ Reference (no decision asked) | Plans and prices of Wix, Squarespace, Webflow, Framer, Hostinger, Jimdo, GoDaddy, Durable, Bootstrap Studio, Blocs, Pinegrow, Elements and Mobirise (Oct 2026), with three years of one site next to Webforge's $99: every hosted builder costs more within a year; among desktop apps Webforge sits between Bootstrap Studio's $59 for life and Elements' $99–249 a year |
| P11 | [Styling one component in depth, and CSS in Advanced mode](product/11-component-theming.md) | ✅ Decided (CT-1…CT-9) | Beyond the Appearance group, in the MVP as Phase 3 items 3.12–3.14: component looks in the theme that later edits follow, with provenance on every control (3.12); a *Style this component…* dialog with a live preview, deeper groups (gradient, border per side, corners, title, spacing, hover) and a choice of this one, every one of its kind or the theme's look (3.13); a read-only CSS view in Advanced mode (3.14). The stylesheet editor is v1.1; per-item layout switches not adopted; per-element CSS stays Later |
| P12 | [Being found: search engines and the exported site](product/12-search-visibility.md) | ✅ Decided (SEO-1…SEO-12) | What Google documents as mattering (and as having no effect), what eight hosted and five desktop builders offer under "SEO", and where Webforge stands: the export already gets the mechanics right, and 3.5 added sitemap, robots, Open Graph and canonical links. All adopted, 28 Oct 2026, as three Phase 3 items (+7.5 days): LocalBusiness structured data from Site Settings with a business type, a per-page *Hide from search engines*, the robots rules, a preloaded first picture, a verification-tag field and `llms.txt` off by default (3.15); a search-result preview that also covers the v1.1 share preview (3.16); a *Being found* group in Site Check (3.17); the quick start as the setup (3.11). A rule against the controls Google says do nothing |
