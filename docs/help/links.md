# Links

Buttons, menu items and text can link somewhere. To add a link:
- **Buttons and other items:** click **Add Link…** in the Edit panel.
- **Text:** select some words while typing and press Ctrl+K (Cmd+K on a Mac), or click **Link…** on the text toolbar.

**Link to** offers five kinds of link:

| Link to | What it does |
|---|---|
| **Page** | Opens one of your pages. Choose a **Section** too, to go straight to that part of the page, such as the opening hours |
| **Email** | Starts an email to the address, with an optional subject |
| **Phone** | Rings the number on a phone |
| **Web address** | Opens another website. Type its address, such as `example.com`; {appName} adds `https://` |
| **File** | Opens or downloads a document from [Media](media.md), such as a PDF menu or price list. Turn on **Download the file instead of opening it** to have visitors save it |

**Open in a new tab** keeps your site open behind the link. It's offered for a page, a web address or a file, and a file opens in a new tab unless you turn it off. Click **Save Link** to add the link.

Links don't open while you edit. Use [Preview](preview.md) to try them.

When you rename a page or change its file name, {appName} updates the links to it. If a page or file a link points to is deleted, [Site Check](site-check.md) lists the broken link.
