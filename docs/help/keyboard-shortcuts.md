# Keyboard shortcuts

Press **?** in {appName}, or choose **Help › Keyboard Shortcuts**, to see these keys for your own computer. Menus show them too.

On a Mac, use **Cmd** wherever this page says **Ctrl**, and **Option** for **Alt**.

## Site

| Keys       | What they do                              |
| ---------- | ----------------------------------------- |
| Ctrl+N     | New Site…                                 |
| Ctrl+O     | Open Site…                                |
| Ctrl+S     | Save now ({appName} also saves by itself) |
| Ctrl+Alt+S | Save Version…                             |
| Ctrl+I     | Preview (when you're not typing text)     |
| Ctrl+E     | Export Site…                              |
| Ctrl+U     | Publish… (when you're not typing text)    |
| Ctrl+,     | Settings…                                 |

## Editing

| Keys                      | What they do                                                             |
| ------------------------- | ------------------------------------------------------------------------ |
| Ctrl+Z                    | Undo                                                                     |
| Ctrl+Shift+Z or Ctrl+Y    | Redo                                                                     |
| Ctrl+X · Ctrl+C · Ctrl+V  | Cut · Copy · Paste                                                       |
| Ctrl+Shift+V              | Paste as Linked Copy (of a shared section)                               |
| Ctrl+Alt+C · Ctrl+Alt+V   | Copy Style · Paste Style                                                 |
| Ctrl+D                    | Duplicate                                                                |
| Delete, or Ctrl+Backspace | Delete (on a Mac, Cmd+Delete: the delete key on its own clears the text) |
| Ctrl+Alt+↑ · Ctrl+Alt+↓   | Move up · Move down (on Windows, Alt+↑ and Alt+↓ too)                    |
| Ctrl+/                    | Don't publish, or show                                                   |
| F2                        | Rename…                                                                  |
| Ctrl+F                    | Find and Replace…                                                        |
| Enter                     | Edit text                                                                |
| Backspace                 | Clear the text and edit it (deletes an item with no text of its own)     |
| Esc                       | Cancel a drag                                                            |

## Selecting

| Keys            | What they do                     |
| --------------- | -------------------------------- |
| ↑ · ↓           | Previous · next item             |
| Ctrl+↑          | Select what contains it          |
| Ctrl+↓          | Select the first thing inside it |
| Ctrl+← · Ctrl+→ | Previous · next item beside it   |

## View

| Keys                     | What they do                                                                                                     |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| Ctrl+P, or Ctrl+K        | Search Commands…                                                                                                 |
| Ctrl+1 · Ctrl+2 · Ctrl+3 | Desktop · Tablet · Mobile                                                                                        |
| Ctrl+= · Ctrl+−          | Zoom the page in · out                                                                                           |
| Ctrl+0                   | Actual size                                                                                                      |
| Ctrl+9                   | Zoom to fit                                                                                                      |
| Ctrl+Alt+= · Ctrl+Alt+−  | Make all of {appName} bigger · smaller (Zoom In Interface · Zoom Out Interface)                                  |
| Ctrl+Alt+0               | Back to 100% (Reset Interface Zoom)                                                                              |
| Ctrl+Shift+O             | Show or hide outlines on the page                                                                                |
| Ctrl+Shift+N             | Show or hide element names on the page                                                                           |
| Ctrl+Alt+B               | Show or hide the left panels                                                                                     |
| Ctrl+J                   | Show or hide the bottom panel (Site Check, Find and Replace)                                                     |
| F6 · Shift+F6            | Next · previous part of the window: the title bar, the left panels, the page, the bottom panel, the right panels |
| ?                        | Keyboard shortcuts                                                                                               |
| F1                       | {appName} Help                                                                                                   |

## While typing text

| Keys                     | What they do                         |
| ------------------------ | ------------------------------------ |
| Ctrl+B · Ctrl+I · Ctrl+U | Bold · italic · underline            |
| Ctrl+K                   | Link…                                |
| Shift+Enter              | New line                             |
| Alt+Enter                | Split into two elements              |
| Shift+Space              | Space that never breaks across lines |

While you type, Ctrl+I, Ctrl+U and Ctrl+K style your text instead of opening Preview, Publish or Search Commands.

## In the Edit panel

| Keys               | What they do                                                                                                                   |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| Ctrl+Enter         | Open or fold every group                                                                                                       |
| Cmd+Esc (Mac only) | Reset the option or group you're on. On Windows, right-click it and choose **Reset to Default** or **Reset Group to Defaults** |
